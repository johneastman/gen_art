# Generative Art

A Python project for creating various types of generative art.

The Sierpiński triangle was inspired by the below Numberphile video:

[![Chaos Game - Numberphile](https://img.youtube.com/vi/kbKtFN71Lfs/0.jpg)](https://www.youtube.com/watch?v=kbKtFN71Lfs "Chaos Game - Numberphile")

## Web App

Run the web app to view and generate art:

```
python app.py
```
